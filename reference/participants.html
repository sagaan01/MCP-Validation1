MCP participants

Quick map of Host, Client, and Server — compressed from the official architecture overview.

Role What it is Example
MCP Host AI application that coordinates one or more MCP clients Cursor, VS Code, Claude Desktop
MCP Client Connector inside the host; one client per connected server Runtime object VS Code creates for Sentry MCP
MCP Server Program that provides context/capabilities to clients Filesystem server (local), Sentry MCP (remote)

Transport (where the server runs)

Transport Typical placement
stdio Local process on the same machine; often one client
Streamable HTTP Remote service; often many clients; auth via HTTP/OAuth
