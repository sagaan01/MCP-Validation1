## How interviewers score you

1. **Concepts** — Can you explain ETL stages and data quality dimensions?
2. **Scenarios** — Can you design checks for a real break (missing trades, wrong fees)?
3. **SQL** — Can you write recon / duplicate / aggregate queries on a whiteboard?
4. **Python** — Can you show a small validation script (pandas / DB / file)?
5. **Judgment** — Severity, gates, source of truth, what belongs in CI vs nightly?
