# Principal SDET Topics — Explained in Layman Terms

This guide explains **every topic** from the Principal SDET job in everyday language.  
If a word sounds technical, we explain it like you’re hearing it for the first time.

---

## How to use this

1. Read these layman guides first (understand the “what” and “why”).
2. Then open the matching numbered file in `interview-prep/` for interview Q&A and code samples.
3. Practice explaining each topic out loud in your own words — that’s what interviewers want.

## One-sentence map of the whole job

> You build **robot checkers** that click the website, call the systems behind it, and verify the **money numbers in the database** are correct — then you plug those checkers into an **automatic assembly line** so bad software can’t ship easily. You also teach others, set standards, and carefully use AI to work faster.
