# Bonus: Everyday Analogies Cheat Sheet

Keep this handy when you need to explain any topic simply in an interview.

| Technical topic | Say it like this |
|-----------------|------------------|
| Manual testing | Taste-testing every cookie by hand |
| Test automation | A machine that taste-tests thousands overnight |
| Playwright | A robot employee controlling a browser |
| Framework | A professional kitchen with shared tools and recipes |
| Page Object | A labeled tool card so recipes stay simple |
| Fixture | Prep work done before you taste the soup |
| Flaky test | Smoke alarm that beeps with no smoke |
| storageState/login reuse | Wristband at the entrance instead of ID every aisle |
| TypeScript | JavaScript with seatbelts/labels |
| API | Waiter between dining room (UI) and kitchen (backend) |
| Backend | The kitchen / back office systems |
| Contract test | Plug-and-socket standard between teams |
| Eventual consistency | Transfer shows “submitted” before balance updates |
| SQL | Asking precise questions to giant Excel-like tables |
| ETL | Collect laundry → wash/sort → put in drawers |
| Reconciliation | Balancing a checkbook across two ledgers |
| Data break | Missing sock between basket and drawer |
| CI | Check each car part as soon as it’s made |
| CD | Move approved cars to next station/shipping |
| Pipeline | Robot cooking checklist |
| Quality gate | Airport security before boarding |
| Azure DevOps | Control room + assembly line |
| Smoke test | “Is the shop basically open?” quick check |
| UAT | Homeowner living-in-the-house walkthrough |
| Wealth platform | Investments + advisor + fees + official reports |
| Position | What holdings you own |
| AUM fee | Management fee based on how much money is managed |
| Copilot | Junior assistant drafting text/code quickly |
| AI guardrails | Rules so speed doesn’t create false safety |
| Principal SDET | Head chef of quality: cooks, designs process, trains, stops bad dishes |
| Mentoring | Teaching cooks better technique with pairing and review |
| Cross-stack testing | Check dining room + waiter + kitchen inventory together |
