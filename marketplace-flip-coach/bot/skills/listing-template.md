# Listing template

Take real photos. Disclose every defect. Never claim a feature you have not verified.

## Title pattern

`{Item} – {Condition} – ${listPrice}`

Example: `Ergonomic Office Chair – Excellent Condition – $75`

## Body pattern

```
{One sentence: what it is + working condition.}

Features:
- {verified feature 1}
- {verified feature 2}
- {verified feature 3}
- Clean and ready to use

Selling because I no longer need it.

Local pickup. First come, first served.
{City / neighborhood if helpful.}

Message me if interested!
```

## Pricing habit

List a little above the target sale so there is room to accept a fair offer.
Example: list chair $75, target sale ~$65.

## Photos

5–7 shots: front, back, sides, any wear, labels/model if present, packed-for-pickup view when useful.
